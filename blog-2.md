On February 13, 2025, the Doxbin database was compromised through an unpatched vulnerability in the Obsidian backend infrastructure.

## Timeline

- **February 9**: Critical vulnerability discovered and disclosed to Hardline's associate
- **February 13**: 4-day remediation deadline expired with no action taken
- **February 13**: Database breach executed and disclosed

## Breach Details

- Full database access obtained via Obsidian backend misconfiguration
- All user data, dox entries, and internal records extracted
- Root cause: Unpatched security flaw in backend infrastructure

## What This Means

Security warnings were issued in good faith. A four-day window was provided for remediation. That window was ignored.

Platform administrators have a responsibility to their users. When you handle sensitive data and ignore critical vulnerabilities, this is the inevitable outcome.

This wasn't about causing harm—it was about accountability. You were warned.
